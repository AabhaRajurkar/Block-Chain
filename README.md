# How Blockchain Works — Animated Explainer

A 60-second educational explainer video introducing blockchain technology, transaction creation, network verification, linked blocks, and practical applications.

## Video

Place the exported video at `video/block-chain-explainer.mp4` after uploading it to this repository.

## Topics covered

- Blockchain as a shared digital ledger
- Creating and broadcasting transactions
- Network validation and consensus
- Linking blocks using cryptographic hashes
- Use cases such as shared records and asset traceability

## Project details

- Format: MP4
- Target duration: approximately 60 seconds
- Intended audience: beginners and students
- Created as a technology explainer project for internship portfolio purposes

## Run / View

Download `video/block-chain-explainer.mp4` from this repository and open it in any standard video player.

## Note

Blockchain security and verification depend on the specific network design and consensus mechanism. This video provides a beginner-level overview, not technical or investment advice.
